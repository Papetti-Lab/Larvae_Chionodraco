# Larvae *Chionodraco*
D-loop sequences used in the paper "Biological traits and identification tools of early life stages of two sympatric species of *Chionodraco* in the Ross Sea" (La Mesa et al., 2026, under review).

This repository contains:
- all the new sequences generated in this study from the larval samples (larvae_Dloop.fasta);
- the sequences from Schiavon et al. (2021) (chionodraco_Dloop.fasta);
- the alignment used to generate the haplotype network with the software Hapsolutely (larvae-chionodraco_Dloop_aligned.fasta);
- the file with the association sequence-group to colour the network in Hapsolutely (larvae-chionodraco_Dloop_partition.txt).
